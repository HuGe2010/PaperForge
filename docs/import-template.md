# 批量导入模板与标记语法（P9 落地，此处为约定）

## Excel 模板（题库）

列：`学科 | 题型 | 题干 | 选项A | 选项B | 选项C | 选项D | 答案 | 解析 | 难度 | 标签 | 知识点`

- 题型取值：`single` / `multiple` / `truefalse` / `fill` / `short` / `essay` / `material`
- 答案：单选填选项字母（如 `A`）；多选填 `A,B`；判断填 `true/false`；填空填 `|` 分隔的多空答案
- 难度：1–5 整数

## Word 导入标记语法

在 Word 中按约定标记，正则解析：

```
【题型】single
【题干】下列属于质数的是？
【选项】A.2  B.4  C.6  D.8
【答案】A
【解析】2 只能被 1 和自身整除。
【难度】2
【知识点】质数与合数
【标签】基础题
```

- `【答案】` / `【解析】` / `【知识点】` / `【题型】` / `【题干】` / `【选项】` / `【难度】` / `【标签】`
- 一道题以 `【题型】` 开始，连续块解析为一条；支持多题批量

## 错误报告

导入后输出 xlsx 错误报告：标红行 + 错误原因列（缺字段 / 题型非法 / 答案与题型不符等）。
