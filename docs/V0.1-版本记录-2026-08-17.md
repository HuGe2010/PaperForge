## 一、这版干了什么（需求闭环）

从零到可用的「图片/PDF → 题库 → 组卷 → 在线考试」全链路，核心是**OCR 自动录题流水线**，围绕它实现了审阅台、题库四分类、OCR 双方案、去重合并等能力。逐项如下：

### 1. 录题流水线（7 步）
上传（PDF 逐页转图、原 PDF 归档）→ AI 自动框选（PaddleOCR 两阶段：本地 OCR 框文字 → 题号/标题正则分组 → 圈出单题框+大题框）→ 人工核对/修改框（拖拽/缩放/增删）→ AI 识别题目（按框调视觉模型，题型由用户指定）→ 标注属性与所属文件 → 入库 → 后台 AI 解答（LLM 异步写回）。

### 2. 审阅台（核心工作台）
- **统一操作区**（顶部）：文件类型二选一（试卷/作业本）+ 试卷名 / 作业本名 + 任意多级章节层级树 + 统一学科 + 一键应用。
- **批量操作**：一键保存、一键入库（逐题查重，相同题自动合并到来源试卷、不重复入库，弹提示统计）。
- **大题分栏**：题目按「一、选择题 / 二、填空题…」分组展示，每题显示题号（AI 识别，题干不含题号）。
- **单题并发识别**：可同时点多题识别，互不打断。
- **跨页截断题合并**：勾选 2 道 → 弹窗预览拼接图（可⇅交换上下）→ 合并为一道题（图片上下拼接、可整题识别）→ 支持「撤销合并」回退。
- **AI 框选进度条**：逐页显示「第 X / Y 页」。
- 填空答案框删除改叉号、简答题支持主题干+多小问。

### 3. 题库管理（四大分类 Tab）
- **按题目**：多维并行筛选（学科、题型、难度、来源、关键字）。
- **按试卷**：试卷列表 + 查看原卷（上传的原始图片/PDF），进入详情按大题结构展示。
- **按作业本**：作业本列表 → 详情按 章节→次标题→次分区 层级树展示（归属显示「作业本名 > 章节 > 次标题 > 次分区」）。
- **按组卷**：组卷包浏览。
- 题目详情：来源试卷（多值，点击跳转过滤）+ 组卷引用（跳智能组卷预览）。

### 4. 去重合并（省 token 设计）
- 第一层粗筛（零 token）：同学科同题型 + 题干 bigram 相似度筛 top5。
- ≥0.9 直接判重；仅 top5 调 LLM 精判（几百 token）。
- 判重命中：不新建题，往已有题「来源试卷」追加卷名（曾修掉 `assignedQuestionId` 唯一约束导致的 P2002）。

### 5. OCR 双方案（后台可切换）
- **本地（PaddleOCR）**：默认、免密钥，Docker 内嵌 OCR 容器（FastAPI + PaddleOCR，内存 ≥3G）。
- **云端（PaddleOCR-VL 异步 job 接口）**：`POST {JOB_URL}` multipart 提交 → 轮询 jobId → 下载 JSONL → 解析版面框（doc_title / paragraph_title / text）。密钥 AES-256-GCM 加密存库，不写镜像/环境变量。
- 系统设置页三组密钥：vlm（视觉识题）、llm（文本解题）、ocr（框选方案）。

### 6. 学科体系
- 9 门默认学科（语数英物化生政史地），seed 内置 + 已写入数据库；AI 识别从名单中选并回填，审阅台可逐题/统一修改。

## 二、技术栈
- 后端：NestJS 11 + Prisma 5 + PostgreSQL 16 + Redis 7（BullMQ 队列）
- 前端：Vue3 + Element Plus + Vite + TypeScript + UnoCSS + ECharts
- OCR 容器：Python + FastAPI + PaddleOCR（本地）/ PaddleOCR-VL（云端，异步 job）
- 部署：Docker Compose（postgres / redis / backend / frontend / ocr 五容器）

## 三、部署方式
```bash
cd putout
cp .env.example .env   # 按需修改端口/数据库密码/AI 密钥
docker compose up -d --build
# 前端 http://<主机>:9280 ，默认账号 admin / Exam@2024!（登录后请改密）
```
- 首次启动自动建表 + 种子（admin/角色/权限/9 学科）。
- AI 密钥在「系统设置」页填写，绝不写入 compose / .env。
