## 1. 审阅台整体结构（自上而下）


## 9. 响应式与关键交互要点

1. **题卡左右对照**：`.review__row` 为 `flex-wrap: wrap`；窄屏（<约 700px 内容宽）时原图与表单自动上下堆叠（图 320px 在上、表单 min-width 300px 在下）。
2. **统一操作区**：`flex-wrap: wrap`，按钮多会自动换行，重设计需考虑两行态。
3. **自动刷新**：审阅台打开期间每 **4s** 轮询服务端；用户正在编辑的题（dirty 标记）不会被服务端数据覆盖——交互设计上可提示「有未保存修改」。
4. **合并题目**：勾选恰好 2 道 → 弹 460px 预览（可 ⇅ 交换上下）→ 确认后生成拼接图替换原图；合并题卡片左上角显示「已合并（跨页拼接）」角标，并可「撤销合并」。
5. **重新识别**：单题「重新识别」按钮支持多题并发（各自 loading）；「重新识别全部」在统一操作区。
6. **空态**：无原图→「无来源原图」占位；无知识点建议→ el-empty 小空态。
7. **禁用逻辑**：已入库（APPROVED）题禁用 重新识别/批准入题/合并勾选；已拒绝（REJECTED）题禁用 拒绝按钮。
8. **对话框高度**：最大 94vh、body 滚动 82vh——重设计建议保留"头部固定 + 列表区滚动"结构。
