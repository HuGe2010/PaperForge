# 智能试卷与试题整理系统 · v0.2 发布说明

题库管理 · 智能组卷 · OCR/PDF 自动录题 · 在线考试 · 自动评分 · PDF/Word 导出

全栈式考试系统，前后端分离，Docker Compose 一键部署。核心特色是「拍照 / PDF 自动录题」：
导入图片或 PDF → 视觉模型识别 → 人工审阅台 → 入题库 → AI 解题 。

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vue 3 + Element Plus + Vite + TypeScript + UnoCSS + ECharts |
| 后端 | NestJS 11 + TypeScript + Prisma 5 |
| 数据库 | PostgreSQL 16（`pg_trgm` 扩展） |
| 缓存 / 队列 | Redis 7 + BullMQ 5 |
| 部署 | Docker Compose（源码本地 build，对外端口 9280） |

> **使用workbuddy 由ai完成**：本版本（含「作业本」模块根因级重构、相关前后端代码与本文档）由 AI 协助完成代码编写与文档整理。

## 二、主要功能

### 2.1 系统级能力（继承自 v0.1）

- **题库管理**：题目录入、编辑、标签、知识点标注、按学科 / 题型 / 难度检索
- **OCR / PDF 自动录题**：导入图片或 PDF → 视觉模型识别 → 自动打标签 → 人工审阅台 → 入题库 → AI 解题 → 标知识点
- **智能组卷**：按条件筛选题目、自动 / 手动组卷、试卷预览
- **在线考试**：发布考试、学生在线答题、倒计时与防作弊基础能力
- **自动评分与解析**：客观题自动判分、主观题留痕、成绩与解析查看
- **导出**：试卷 / 答题卡 PDF、Word 导出

### 2.2 v0.2 重点：作业本（Workbook）模块

**根因问题（v0.1）**：旧版用「名称路径快照」`sourcePath`（如 `['暑假作业','第十七练','1']`）判定题目归属。一旦重命名作业本、重命名章节或移动章节，题目路径从不回写，导致题目在所有章节与「作业本根」都匹配不到 → **题目凭空消失、不可恢复**。

**修复方案**：题目归属改为 `Question.workbookId + Question.workbookSectionId` 外键（唯一真相），`sourcePath` 降为派生展示字段，由统一逻辑在变更后自动重算。

**v0.2 作业本功能点**：

- 任意层级章节均可挂题（去除旧版「仅最末级章节可加题」的反直觉限制）
- 重命名作业本 / 章节、移动章节后，题目**不再丢失**，展示路径自动重算
- 删除章节：其下题目**移出作业本、回到题库**（题目不删除，可在题库找回）
- 单题「移动」到其他章节、「移出」回题库
- 章节树支持同级**上移 / 下移**调整顺序
- 「编辑属性」弹窗：修改作业本名称 / 学科 / 描述
- 权限收紧：作业本的列表、详情、题目接口仅 **教师 / 管理员** 可见（学生不可读）
- UI 调整：浏览态提供「管理作业本」入口；打开作业本默认展开第一个章节；隐藏「作业本根」节点

## 三、如何部署（Docker Compose）

> 部署入口就是仓库**根目录**的 `docker-compose.yml`，它直接从根上下文构建 `backend` / `frontend` / `ocr` 三个服务并自带 `postgres` / `redis`，**不依赖 `putout/` 目录**。

### 3.1 标准部署步骤

```bash
# 1) 准备环境变量（必须，compose 依赖其中的数据库 / JWT 等变量）
cp .env.example .env
#    至少修改：POSTGRES_PASSWORD、JWT_SECRET、JWT_REFRESH_SECRET
#    （建议也修改 POSTGRES_USER / POSTGRES_DB 与默认管理员密码）

# 2) 构建并启动（前端对外端口默认 9280，可在 .env 用 WEB_PORT 改）
docker compose build
docker compose up -d

# 3) 打开浏览器
#    http://<服务器IP>:9280
#    首次管理员账号见下方「默认管理员」
```

- 后端容器启动时会**自动执行 `prisma migrate deploy`** 应用数据库迁移，无需手动跑。
- 全部服务健康后，前端首页即可访问。数据持久化在仓库内的 `./data/` 卷（已排除在版本库外）。

### 3.2 必须配置的环境变量（`.env`）

| 变量 | 是否必填 | 说明 |
|---|---|---|
| `POSTGRES_USER` / `POSTGRES_PASSWORD` / `POSTGRES_DB` | 必填 | 数据库账号、密码、库名 |
| `JWT_SECRET` / `JWT_REFRESH_SECRET` | 必填 | 令牌签名密钥，**生产务必改成随机长字符串** |
| `WEB_PORT` | 可选 | 前端对外端口，默认 `9280` |
| `LLM_*` / `VLM_*` | 可选 | 解题 / 录题用的文本与视觉模型 Key；**不配也能跑题库、作业本、组卷等基础功能**，仅 AI 解题 / 智能识题不可用 |
| `OCR_SERVICE_URL` | 可选 | 试卷 OCR 框选服务地址，默认 `http://ocr:8000`（同 compose 内服务） |

> 数据库与 Redis 默认不对外暴露端口，仅容器内互通，安全且无需额外开放。

### 3.3 默认管理员

- 用户名：`admin`
- 密码：`Exam@2024!`（首次登录后请**立即修改**，种子在 `prisma` 种子脚本中）

### 3.4 端口

| 服务 | 端口 | 说明 |
|---|---|---|
| 前端 | 9280 | 对外访问入口（nginx 反代 `/api` → backend:3000） |
| 后端 | 3000 | 内部 API |
| PostgreSQL | 5432 | 数据库（默认不对外暴露） |
| Redis | 6379 | 缓存 / 队列（默认不对外暴露） |

### 3.5 本地开发（非 Docker）

```bash
cp .env.example .env
npm install                 # 安装前后端依赖（workspace）
npm run prisma:generate     # 生成 Prisma Client
npm run prisma:migrate      # 执行数据库迁移
npm run prisma:seed         # 写入管理员 + 三角色 + 权限种子
npm run dev:backend         # 后端 :3000
npm run dev:frontend        # 前端 :5173
```

## 四、使用说明（快速上手）

### 4.1 登录与角色

- 打开 `http://<服务器IP>:9280`，用管理员 / 教师 / 学生账号登录。
- **管理员**：用户 / 角色 / 权限管理、系统设置（AI Key）、全站数据。
- **教师**：题库维护、作业本、智能组卷、试卷导出、发布考试、阅卷。
- **学生**：在线答题、查看成绩与解析。
- 作业本功能仅对**教师 / 管理员**可见。

### 4.2 题库与录题

1. 进入「题库」：可新建 / 编辑题目，按学科、题型、难度、标签筛选检索。
2. 自动录题：导入图片或 PDF → 视觉模型识别 → 进入「审阅台」人工校正 → 确认入库 →（可选）AI 解题并标知识点。

### 4.3 作业本（v0.2 重点操作流程）

> 目标：把题库里的题组织成「作业本 → 多级章节 → 题目」的结构，便于布置与下发。

1. **新建作业本**：在「题库 / 按作业本」Tab 点击新建，填写名称（可填学科 / 描述）。
2. **打开作业本**：点击作业本进入抽屉，**默认展开第一个章节**。
3. **管理章节（左侧树）**：
   - 「新建」：新建一级章节；在章节上「+」可建**任意层级子章节**。
   - 「重命名」：修改章节名（改名后题目不丢失，路径自动重算）。
   - 「上移 / 下移」：同级内调整顺序。
   - 「删除」：删除章节，**其下题目自动移出作业本、回到题库**（题目不删除）。
4. **添加题目到章节**：
   - 点底部「**管理作业本**」进入编辑态；
   - 在左侧选中某个章节（根或任意层级均可）；
   - 点「添加题目到作业本」→ 右侧题库勾选 → 「确认添加」。
   - ✅ v0.2 去除旧版「仅最末级章节可加题」限制，**任意层级章节都能挂题**。
5. **单题操作**（题目行右侧）：
   - 「移动」：弹窗选择目标章节（含「作业本根（未分章节）」），跨章节移动；
   - 「移出」：把题移出作业本、回题库（题目不删）。
6. **编辑作业本属性**：点「编辑属性」，修改名称 / 学科 / 描述并保存。
7. **完成**：编辑态点「完成」回到只读浏览。

> 常见反直觉已修复：重命名作业本 / 章节、移动章节后题目**不会消失**；删除章节只是把题退回题库，可随时找回。

### 4.4 组卷与导出

- 「组卷」：按条件筛选题目，自动 / 手动组成试卷，可预览。
- 导出：试卷 / 答题卡支持 **PDF**、**Word** 导出。

### 4.5 考试与评分

- 「考试」：发布试卷给学生，学生在线答题（含倒计时等基础防作弊）。
- 评分：客观题自动判分，主观题留痕批阅；学生可查看成绩与解析。

### 4.6 数据备份

- 所有业务数据在 `./data/`（postgres / redis / uploads / exports 卷）。迁移或重装前请备份该目录（详见 `docs/deploy.md`）。

## 五、从 v0.1 升级

1. 用 v0.2 代码（根目录）替换旧代码，保留原有 `.env` 与数据卷 `./data/`。
2. 重新构建并启动：`docker compose build && docker compose up -d`。
3. 后端启动会自动应用迁移 **`20260818100000_question_workbook_section_fk`**：
   - 用递归 CTE 按旧 `sourcePath` 反解并回填 `workbookSectionId` 外键；
   - 规范化题目展示路径；历史「未分章节」题目收敛为作业本根。
   - 该迁移为**纯增量、幂等、可回退**。
4. 升级后旧作业本数据无需手工处理即可正常使用。

> 升级前建议对数据库做一次备份（见 `docs/deploy.md`）。
